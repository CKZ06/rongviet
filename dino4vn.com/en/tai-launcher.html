Talk to the players near you

Open the launcher, join the game, and just talk. Anyone standing close hears you, hears which direction you are in and how far away, just like in real life.

Four steps

  1. Download the launcher

    Download for Windows (0.3.2)

  2. Run the installer

    Windows will warn you once because the file has no purchased code-signing certificate. Click More info → Run anyway.

  3. Open the launcher, sign in with Steam, click Play

    Signing in opens your browser. Your Steam password never goes through the launcher.

  4. Talk

    Nothing else to press. Just talk and the people near you will hear you.

A few things to know first

  • Use headphones. With speakers, other people's voices leak back into your microphone and everyone hears their own echo.
  • The microphone is only on while The Isle is running. Close the game and the microphone closes with it. You can change this in Settings if you prefer.
  • Only nearby players can hear you. Go too far and your voice fades out completely, as in real life, and the same goes for how you hear others.
  • If it doesn't sound right, you can adjust it. Settings let you pick your microphone and headphones, show a level meter so you can see whether you are talking loudly or quietly, and have a mute button.
  • The launcher does not interfere with the game: it does not read memory and does not modify anything in the game process. It only uses your microphone and speakers, like any normal voice call app.

Can't hear anyone?

  • Check the status line at the left corner of the launcher. It tells you plainly what is in the way: not signed in, not in the game yet, or the microphone can't be opened.
  • You must have spawned in the game. On the species selection screen you have no position yet, so there is nobody to hear.
  • Windows may be blocking the microphone: Settings → Privacy → Microphone, and turn it on for desktop apps.
  • Still not working? Message us on Discord and include the status line you see.

Frequently asked questions

Will this app get me banned by EasyAntiCheat?

This is the first question to ask when installing anything that runs alongside The Isle, so here is everything the launcher does not do:

  • It does not modify any game file. It is not a mod.
  • It does not run inside the game process, does not hook into the game, and does not read game memory.
  • It does not press keys or click the mouse for you.
  • It is just an ordinary Windows window floating on top, the same kind as the Discord overlay or a browser placed over the game.
  • Every number it shows comes from Rong Viet's server, not pulled out of your computer.

We can't speak for Epic or EasyAntiCheat. Nobody can. But that is everything the app does and doesn't do, and you can check it yourself using the section below.

Verify the downloaded file

The file isn't code-signed, so the surest way to know you got our real file is to compare the checksum. Open PowerShell and paste:

Get-FileHash "$env:USERPROFILE\Downloads\RongVietLauncher-Setup-0.3.2.exe" -Algorithm SHA256

The result must match this string exactly:

ba10553038fd9edac50334a36d1f224e3429fc26b35767a11d5b8157986d0a31

If even one character differs, don't run it. Download it again from this page.

The overlay doesn't show up in the game

Almost always one cause: the game is running in true Fullscreen. Windows doesn't let any window float above that mode. This is a Windows limitation, not a launcher bug.

In The Isle go to Settings → Video → Window Mode and choose Borderless (or Windowed Fullscreen). It looks exactly like fullscreen, and alt-tab is even faster.

How do I uninstall it?

Settings → Apps → Installed apps → Rong Viet Launcher → Uninstall. That's it: the game is not affected and you can still join the server as usual.

Is this the voice launcher other servers tell me to install?

No. That one is IsleVOIP, made by someone else, and many Vietnamese servers use it. The Rong Viet launcher is our own app, with proximity voice built in. On Rong Viet only this launcher works; the other one won't let you hear anyone.
